My Skills

HTML

HTML is used to create the structure of a webpage. It defines headings, paragraphs, images, links, tables, and forms.

CSS

CSS is used to style a webpage. It controls colors, fonts, spacing, layout, borders, and responsive design.

JavaScript

JavaScript is used to make webpages interactive. It helps add actions like button clicks, sliders, popups, and form validation.

Bootstrap

Bootstrap is a CSS framework used to create responsive websites quickly. It provides ready-made classes for grids, buttons, cards, navbar, and layout.

Python

Python is a simple and powerful programming language. It is used for web development, data analysis, automation, AI, and backend development.

Django

Django is a Python web framework used to build websites and web applications quickly. It helps with database handling, URL routing, templates, login system, and backend development.
